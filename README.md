# ফাতিহ ’২১ · অতীত থেকে ভবিষ্যৎ

রুয়েট ’২১ সিরিজের (ফাতিহ ’২১) বিদায়ী আয়োজনের ওয়েবসাইট: মক্কা বিজয় কুইজ ও আধুনিক খিলাফতের অর্থব্যবস্থা কেস স্টাডি।
সাধারণ স্ট্যাটিক সাইট (HTML/CSS/JS), কোনো বিল্ড কমান্ড লাগে না।

## ফাইল

| ফাইল | কাজ |
|---|---|
| `index.html` | পুরো পেজ |
| `style.css` | ডিজাইন |
| `app.js` | নোটিশ, সময় গণনা, ট্যাব |
| `data.js` | **নোটিশ ও ফোন নম্বর** (এখানেই বদলাতে হয়) |
| `assets/` | লোগো, ফন্ট, মক্কা বিজয় পিডিএফ, কেস স্টাডি টেমপ্লেট |

## নোটিশ যোগ করা

`data.js`-এর `window.NOTICES` তালিকার একদম ওপরে নতুন ব্লক বসান:

```js
{
  date: "2026-11-20",
  title: "কুইজের সময় জানানো হলো",
  body: "কুইজ শুরু হবে সন্ধ্যা ৭টায়।",
  link: { text: "ফেসবুক পেজ", url: "https://..." },   // ঐচ্ছিক
  pinned: false                                         // true দিলে সবার ওপরে থাকবে
},
```

## ফোন নম্বর

`data.js`-এ `phone: "01XXXXXXXXX"` লিখলে ফুটারে দেখাবে।
